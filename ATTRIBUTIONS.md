# Attributions

- Primary dataset: Thought Vector, **Customer Support on Twitter**, Kaggle dataset `thoughtvector/customer-support-on-twitter`.
- Dataset schema/thread linkage follows the Kaggle documentation (`tweet_id`, `author_id`, `inbound`, `response_tweet_id`, `in_response_to_tweet_id`).
- pandas and scikit-learn are used for data processing and models.
- During preparation, a public GitHub Hiver-assessment repository was inspected only to confirm AppleSupport was a practical brand choice and a 200-example workflow was feasible; no reported metrics or implementation code were copied.
